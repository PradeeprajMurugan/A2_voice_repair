# Sous — barge-in repair for a hands-busy kitchen voice assistant

Assignment 2 prototype, Intelligent Interactive Systems (University of Birmingham).

> Status: work in progress. This README will be completed as the prototype develops.

## Project status

- [ ] Mock kitchen actions (call, timer, music, shopping list)
- [ ] Intent parser with repair-marker detection
- [ ] Act / confirm / ask policy
- [ ] Dialogue manager with undo-first repair and clarification
- [ ] Scenario replay tests
- [ ] Browser UI with speech in/out and kitchen-noise simulation
- [ ] Optional LLM intent parser

See [docs/design_notes.md](docs/design_notes.md) for the problem carried forward from Assignment 1 and Lab 3.
